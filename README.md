# AI Notes Doubt Solver V2

## New V2 features
- Floating Ask AI button
- Select PDF text and instantly ask AI
- Voice doubt input
- Upload a question/image for AI analysis
- Current page summary
- Generate 5 MCQs
- Chat history
- Mobile responsive interface

## Setup
```bash
npm install
```

Copy `.env.example` to `.env` and add your server-side API key.

```bash
npm start
```

Open `http://localhost:3000`.

Never place your API key in `public/` files.
